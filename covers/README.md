# Project covers

Drop an image in this folder named after the repository and it becomes that project's cover on the next deploy.

    covers/glacial.png        ->  Glacial
    covers/nz-ecosim.webp     ->  nz-ecosim

Names aren't case-sensitive. Use webp, png, jpg, gif, svg or avif. Covers are shown at 16:10, so around 1600 x 1000 px works well.

A cover here beats every other source except a `cover` set in `dashboard.config.json`.
